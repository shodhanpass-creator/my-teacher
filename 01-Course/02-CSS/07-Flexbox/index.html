CSS Flexbox

📖 Reading time: 25 minutes 🎯 Difficulty: Intermediate

What is Flexbox?

Flexbox is a one-dimensional layout system in CSS. It makes it easy to align and distribute space among items in a container, even when their size is unknown or dynamic.

💡 Think of it this way:

Imagine you're arranging books on a shelf. Flexbox is like having a magical shelf that automatically adjusts the spacing and alignment of your books, no matter how many there are or how thick they are!

Why Flexbox?

  • Easy centering of elements
  • Equal distribution of space
  • Responsive layouts without floats
  • Simple ordering of elements
  • Works with unknown sizes

The Flex Container

To use Flexbox, you make a parent element a flex container by setting display: flex;

📄 Basic Flex Container
.container {
    display: flex;  /* This makes it a flex container */
}

Flex Direction

The flex-direction property defines the direction of the main axis (how items are laid out).

📄 Flex Direction Values
.container {
    /* Default - items go left to right */
    flex-direction: row;
    
    /* Items go right to left */
    flex-direction: row-reverse;
    
    /* Items go top to bottom */
    flex-direction: column;
    
    /* Items go bottom to top */
    flex-direction: column-reverse;
}

Justify Content (Main Axis)

justify-content aligns items along the main axis (left-right in row, top-bottom in column).

📄 Justify Content Values
.container {
    /* Default - items packed at start */
    justify-content: flex-start;
    
    /* Items packed at end */
    justify-content: flex-end;
    
    /* Items centered */
    justify-content: center;
    
    /* Equal space between items */
    justify-content: space-between;
    
    /* Equal space around items */
    justify-content: space-around;
    
    /* Equal space between and around items */
    justify-content: space-evenly;
}

Align Items (Cross Axis)

align-items aligns items along the cross axis (top-bottom in row, left-right in column).

📄 Align Items Values
.container {
    /* Default - stretches to fill container */
    align-items: stretch;
    
    /* Items at the top */
    align-items: flex-start;
    
    /* Items at the bottom */
    align-items: flex-end;
    
    /* Items centered vertically */
    align-items: center;
    
    /* Items based on text baseline */
    align-items: baseline;
}

Flex Wrap

By default, flex items try to fit on one line. flex-wrap allows them to wrap to the next line.

📄 Flex Wrap
.container {
    /* Default - items stay on one line */
    flex-wrap: nowrap;
    
    /* Items wrap to next line */
    flex-wrap: wrap;
    
    /* Items wrap in reverse */
    flex-wrap: wrap-reverse;
}

Flex Item Properties

📄 Flex Item Properties
.item {
    /* Grow factor - how much item should grow */
    flex-grow: 1;  /* Takes available space */
    flex-grow: 0;  /* Don't grow (default) */
    
    /* Shrink factor - how much item should shrink */
    flex-shrink: 1;  /* Can shrink (default) */
    flex-shrink: 0;  /* Don't shrink */
    
    /* Basis - initial size before growing/shrinking */
    flex-basis: 200px;
    flex-basis: auto;
    
    /* Shorthand */
    flex: 1;           /* grow: 1, shrink: 1, basis: 0 */
    flex: 0 0 200px;   /* grow: 0, shrink: 0, basis: 200px */
    flex: 1 1 auto;    /* grow: 1, shrink: 1, basis: auto */
    
    /* Order - change visual order */
    order: 1;  /* Move to end */
    order: -1; /* Move to start */
    
    /* Align Self - override container's align-items */
    align-self: center;
    align-self: flex-start;
    align-self: flex-end;
}

Common Flexbox Patterns

Pattern 1: Centering Anything

📄 Perfect Centering
.center-container {
    display: flex;
    justify-content: center;
    align-items: center;
    height: 100vh;  /* Full viewport height */
}

Pattern 2: Navigation Bar

📄 Navbar Layout
.navbar {
    display: flex;
    justify-content: space-between;
    align-items: center;
    padding: 1rem 2rem;
}

.logo { /* Logo on left */ }
.nav-links { /* Links on right */ }

Pattern 3: Card Grid

📄 Card Grid
.card-container {
    display: flex;
    flex-wrap: wrap;
    gap: 20px;
}

.card {
    flex: 1 1 300px;  /* Grow, shrink, min 300px */
    max-width: 400px;
}

Pattern 4: Sticky Footer

📄 Sticky Footer
body {
    display: flex;
    flex-direction: column;
    min-height: 100vh;
}

main {
    flex: 1;  /* Takes remaining space */
}

footer {
    /* Sits at bottom */
}
