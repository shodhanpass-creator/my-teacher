CSS Basics

📖 Reading time: 20 minutes 🎯 Difficulty: Beginner

What is CSS?

CSS stands for Cascading Style Sheets. It's the language that makes websites look beautiful. While HTML provides the structure, CSS provides the style.

💡 Think of it this way:

HTML is like a naked mannequin in a store window. CSS is the clothes, makeup, and jewelry that make it look stunning!

╔══════════════════════════════════════════════════════════════╗ ║ CSS: THE THREE C'S ║ ╚══════════════════════════════════════════════════════════════╝ C - CASCADING Multiple rules can apply to the same element. Later rules override earlier ones (unless !important). Think: Like layers of paint - last coat covers previous. S - STYLE Defines how things look: colors, fonts, sizes, spacing. Think: The visual appearance of clothes. S - SHEETS Rules are organized in style sheets (files or tags). Think: A recipe book for styling your webpage.

Three Ways to Add CSS

There are three ways to add CSS to your HTML:

Method 1: Inline CSS (inside the element)

📄 Inline CSS
<p style="color: blue; font-size: 18px;">This is blue text</p>
⚠️ When to use:

Only for quick testing. Hard to maintain for large projects. Avoid for real websites.

Method 2: Internal CSS (in <head>)

📄 Internal CSS
<head>
    <style>
        p {
            color: blue;
            font-size: 18px;
        }
        h1 {
            color: red;
        }
    </style>
</head>
When to use:

For single-page websites or when you need page-specific styles.

Method 3: External CSS (BEST - separate file)

📄 External CSS
<!-- HTML file -->
<head>
    <link rel="stylesheet" href="styles.css">
</head>

/* styles.css file */
p {
    color: blue;
    font-size: 18px;
}

h1 {
    color: red;
}
✅ BEST METHOD:

Use external CSS files for all real projects. It keeps your code organized, reusable, and easy to maintain.

CSS Syntax

Every CSS rule has two parts: a selector and declarations.

CSS RULE STRUCTURE: selector { property: value; property: value; } Example: p { color: blue; font-size: 18px; text-align: center; } ┌─────────┐ ┌─────────────────────────────────────┐ │ SELECTOR│ │ DECLARATIONS │ │ (who?) │ │ (what to change?) │ └─────────┘ └─────────────────────────────────────┘ p { color: blue; font-size: 18px; } ^ ^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^ "Which "Make it blue and 18 pixels" element?"
💡 Breaking it down:
  • Selector = WHO to style (p, h1, .class, #id)
  • Property = WHAT to change (color, font-size, margin)
  • Value = HOW to change it (blue, 18px, 10px)
  • Declaration = property: value;

Basic CSS Selectors

Selectors tell CSS which HTML element(s) to style.

📄 Basic Selectors
/* Element Selector - selects ALL elements of that type */
p {
    color: blue;
}

/* Class Selector - selects elements with class="name" */
.my-class {
    color: red;
}

/* ID Selector - selects element with id="name" */
#my-id {
    color: green;
}

/* Universal Selector - selects ALL elements */
* {
    margin: 0;
    padding: 0;
}
SELECTOR CHEAT SHEET: Selector Example What it selects ───────────────────────────────────────────────────── Element p All <p> elements Class .btn All class="btn" elements ID #header Only id="header" element Universal * All elements Grouping h1, h2, h3 All h1, h2, and h3 Descendant div p All p inside div Child div > p Direct children p of div Adjacent Sibling h1 + p First p after h1

CSS Colors

CSS supports many ways to define colors:

📄 Color Methods
/* Named Colors */
p { color: red; }
p { color: blue; }
p { color: tomato; }

/* Hex Colors (# followed by 6 characters) */
p { color: #ff0000; }      /* Red */
p { color: #00ff00; }      /* Green */
p { color: #0000ff; }      /* Blue */
p { color: #333333; }      /* Dark gray */

/* RGB (Red, Green, Blue) */
p { color: rgb(255, 0, 0); }       /* Red */
p { color: rgb(0, 255, 0); }       /* Green */
p { color: rgb(0, 0, 255); }       /* Blue */
p { color: rgba(0, 0, 255, 0.5); } /* Semi-transparent blue */

/* HSL (Hue, Saturation, Lightness) */
p { color: hsl(0, 100%, 50%); }        /* Red */
p { color: hsl(120, 100%, 50%); }      /* Green */
p { color: hsla(240, 100%, 50%, 0.5); }/* Semi-transparent blue */

CSS Typography

📄 Font Properties
p {
    /* Font Family - which font to use */
    font-family: 'Arial', 'Helvetica', sans-serif;
    
    /* Font Size - how big the text is */
    font-size: 18px;
    font-size: 1.2rem;  /* Relative to parent */
    font-size: 120%;    /* Percentage of parent */
    
    /* Font Weight - how bold */
    font-weight: normal;  /* 400 */
    font-weight: bold;    /* 700 */
    font-weight: 300;     /* Light */
    
    /* Font Style */
    font-style: italic;
    font-style: normal;
    
    /* Text Color */
    color: #333333;
    
    /* Line Height - space between lines */
    line-height: 1.6;
    
    /* Text Alignment */
    text-align: left;
    text-align: center;
    text-align: right;
    
    /* Text Decoration */
    text-decoration: none;
    text-decoration: underline;
    text-decoration: line-through;
    
    /* Text Transform */
    text-transform: uppercase;
    text-transform: lowercase;
    text-transform: capitalize;
}

The Box Model

Every element in CSS is a rectangular box. The box model defines how much space an element takes up.

╔══════════════════════════════════════════════════════════════╗ ║ THE CSS BOX MODEL ║ ╚══════════════════════════════════════════════════════════════╝ ┌─────────────────────────────────────────────┐ │ MARGIN │ │ (Space OUTSIDE the border) │ │ ┌─────────────────────────────────────┐ │ │ │ BORDER │ │ │ │ (Line around the element) │ │ │ │ ┌─────────────────────────────┐ │ │ │ │ │ PADDING │ │ │ │ │ │ (Space INSIDE the border) │ │ │ │ │ │ ┌─────────────────────┐ │ │ │ │ │ │ │ CONTENT │ │ │ │ │ │ │ │ (Text, images) │ │ │ │ │ │ │ └─────────────────────┘ │ │ │ │ │ └─────────────────────────────┘ │ │ │ └─────────────────────────────────────┘ │ └─────────────────────────────────────────────┘ Content: The actual content (text, images) Padding: Space between content and border Border: The visible border around the element Margin: Space outside the border (between elements)
📄 Box Model Example
.box {
    /* Content */
    width: 300px;
    height: 200px;
    
    /* Padding (inside border) */
    padding: 20px;          /* All sides */
    padding-top: 10px;      /* Top only */
    padding: 10px 20px;     /* Top/Bottom, Left/Right */
    padding: 10px 20px 30px 40px; /* Top, Right, Bottom, Left */
    
    /* Border */
    border: 2px solid black;
    border-radius: 10px;    /* Rounded corners */
    
    /* Margin (outside border) */
    margin: 20px;
    margin: 10px auto;      /* Center horizontally */
}
✅ Pro Tip: box-sizing

By default, width/height only includes the content. Add box-sizing: border-box; to include padding and border in the width. This makes layout much easier!

The Display Property

The display property controls how an element is rendered.

📄 Display Values
/* Block - takes full width, starts new line */
div {
    display: block;
}

/* Inline - only takes needed width, no new line */
span {
    display: inline;
}

/* Inline-block - inline but can have width/height */
.btn {
    display: inline-block;
    width: 100px;
    height: 40px;
}

/* Flex - for flexbox layout */
.container {
    display: flex;
}

/* Grid - for grid layout */
.grid-container {
    display: grid;
}

/* None - hides element completely */
.hidden {
    display: none;
}

The Position Property

📄 Position Values
/* Static - default, normal flow */
.box {
    position: static;
}

/* Relative - relative to its normal position */
.box {
    position: relative;
    top: 10px;    /* Move 10px down */
    left: 20px;   /* Move 20px right */
}

/* Absolute - relative to nearest positioned ancestor */
.box {
    position: absolute;
    top: 0;
    right: 0;
}

/* Fixed - relative to viewport (stays in place when scrolling) */
.header {
    position: fixed;
    top: 0;
    width: 100%;
}

/* Sticky - hybrid of relative and fixed */
.nav {
    position: sticky;
    top: 0;
}
