JavaScript Basics

📖 Reading time: 25 minutes 🎯 Difficulty: Beginner

What is JavaScript?

JavaScript is a programming language that makes websites interactive. While HTML provides structure and CSS provides style, JavaScript provides behavior.

💡 Think of it this way:

If HTML is the skeleton and CSS is the clothing, then JavaScript is the brain and muscles. It makes the page think, move, and respond to your actions!

What Can JavaScript Do?

  • Respond to button clicks
  • Validate form inputs
  • Change HTML content dynamically
  • Change CSS styles
  • Fetch data from servers
  • Create animations
  • Build games
  • And much more!

Where to Write JavaScript

There are three ways to add JavaScript to your HTML:

Method 1: Internal JavaScript (in <script> tag)

📄 Internal JS
<script>
    alert('Hello, World!');
</script>

Method 2: External JavaScript (BEST)

📄 External JS
<!-- HTML file -->
<script src="script.js"></script>

// script.js file
alert('Hello, World!');
✅ Best Practice:

Always use external JavaScript files. It keeps your code organized and the browser can cache the file for faster loading.

Method 3: Inline JavaScript (AVOID)

📄 Inline JS (Avoid!)
<button onclick="alert('Clicked!')">Click Me</button>

Variables

Variables are like labeled boxes that store information. You give the box a name, and you can put things in it, take things out, or change what's inside.

💡 Think of it this way:

A variable is like a labeled jar. The label is the variable name, and the jar can hold different things (values). You can put cookies in it, then later replace them with candies.

Three Ways to Declare Variables

📄 Variable Declarations
// var - old way, avoid using
var name = "John";

// let - can be changed (reassigned)
let age = 25;
age = 26;  // This is OK

// const - cannot be changed (constant)
const PI = 3.14159;
PI = 3;  // ERROR! Cannot change const
VAR vs LET vs CONST: var name = "John"; ├── Can be redeclared ├── Can be reassigned ├── Function scoped (old behavior) └── ❌ AVOID using this let age = 25; ├── Cannot be redeclared ├── CAN be reassigned ├── Block scoped (modern) └── ✅ Use when value changes const PI = 3.14; ├── Cannot be redeclared ├── Cannot be reassigned ├── Block scoped (modern) └── ✅ Use when value stays same

Data Types

Data types tell JavaScript what kind of value you're working with.

📄 JavaScript Data Types
// STRING - text (always in quotes)
let name = "John";
let greeting = 'Hello';
let message = `Hi ${name}`;  // Template literal

// NUMBER - integers and decimals
let age = 25;
let price = 19.99;
let negative = -10;

// BOOLEAN - true or false
let isStudent = true;
let isGraduated = false;

// UNDEFINED - declared but no value
let x;
console.log(x);  // undefined

// NULL - intentionally empty
let empty = null;

// OBJECT - key-value pairs
let person = {
    name: "John",
    age: 25,
    isStudent: true
};

// ARRAY - list of values
let colors = ["red", "blue", "green"];
let numbers = [1, 2, 3, 4, 5];
DATA TYPES VISUAL: String: "Hello" → Text in quotes Number: 42 → Just a number Boolean: true/false → Yes/No answer Undefined: undefined → No value yet Null: null → Empty on purpose Object: {key: val} → Key-value pairs Array: [1, 2, 3] → Ordered list

Operators

Arithmetic Operators

📄 Math Operations
let a = 10;
let b = 3;

console.log(a + b);   // 13 (addition)
console.log(a - b);   // 7  (subtraction)
console.log(a * b);   // 30 (multiplication)
console.log(a / b);   // 3.333... (division)
console.log(a % b);   // 1  (modulus - remainder)
console.log(a ** b);  // 1000 (exponent - power)

Comparison Operators

📄 Comparisons
let x = 5;

// Equal to (value only)
console.log(x == "5");    // true (loose comparison)
console.log(x === "5");   // false (strict comparison)

// Not equal to
console.log(x != "5");    // false
console.log(x !== "5");   // true

// Greater/Less than
console.log(x > 3);       // true
console.log(x < 10);      // true
console.log(x >= 5);      // true
console.log(x <= 4);      // false
⚠️ == vs ===

== compares values only (type coercion). === compares values AND types. Always use === for predictable results!

Logical Operators

📄 Logical Operations
let a = true;
let b = false;

// AND - both must be true
console.log(a && b);   // false

// OR - at least one must be true
console.log(a || b);   // true

// NOT - flips the value
console.log(!a);       // false

Conditionals (If/Else)

Conditionals let your code make decisions based on conditions.

📄 If/Else Statements
let age = 18;

// Basic if
if (age >= 18) {
    console.log("You can vote!");
}

// If/Else
if (age >= 18) {
    console.log("Adult");
} else {
    console.log("Minor");
}

// If/Else If/Else
if (age < 13) {
    console.log("Child");
} else if (age < 18) {
    console.log("Teenager");
} else {
    console.log("Adult");
}

// Ternary Operator (shorthand)
let status = age >= 18 ? "Adult" : "Minor";
console.log(status);  // "Adult"
📄 Switch Statement
let day = "Monday";

switch (day) {
    case "Monday":
        console.log("Start of work week");
        break;
    case "Friday":
        console.log("Almost weekend!");
        break;
    case "Saturday":
    case "Sunday":
        console.log("Weekend!");
        break;
    default:
        console.log("Regular day");
}

Loops

Loops repeat code multiple times.

📄 For Loop
// Basic for loop
for (let i = 0; i < 5; i++) {
    console.log(i);  // 0, 1, 2, 3, 4
}

// Loop through array
let colors = ["red", "blue", "green"];
for (let i = 0; i < colors.length; i++) {
    console.log(colors[i]);
}
📄 While Loop
// While loop
let count = 0;
while (count < 5) {
    console.log(count);
    count++;
}

// Do/while loop (runs at least once)
let num = 10;
do {
    console.log(num);
    num--;
} while (num > 0);
📄 For...of and For...in
// For...of - loops through VALUES
let fruits = ["apple", "banana", "orange"];
for (let fruit of fruits) {
    console.log(fruit);
}

// For...in - loops through KEYS
let person = { name: "John", age: 25 };
for (let key in person) {
    console.log(key + ": " + person[key]);
}

Functions

Functions are reusable blocks of code. Write once, use many times!

💡 Think of it this way:

A function is like a recipe. You write the steps once (function definition), and then you can follow that recipe anytime (function call) to make the same dish.

📄 Function Declarations
// Function Declaration
function greet(name) {
    return "Hello, " + name + "!";
}

// Function Expression
const add = function(a, b) {
    return a + b;
};

// Arrow Function (ES6+)
const multiply = (a, b) => a * b;

// Using the functions
console.log(greet("John"));      // "Hello, John!"
console.log(add(5, 3));          // 8
console.log(multiply(4, 2));     // 8
📄 Function Parameters
// Default parameters
function greet(name = "World") {
    return `Hello, ${name}!`;
}
console.log(greet());        // "Hello, World!"
console.log(greet("John"));  // "Hello, John!"

// Rest parameters
function sum(...numbers) {
    return numbers.reduce((total, num) => total + num, 0);
}
console.log(sum(1, 2, 3, 4));  // 10

Arrays

Arrays are ordered lists of values. They can hold any data type.

📄 Array Basics
// Creating arrays
let fruits = ["apple", "banana", "orange"];
let numbers = [1, 2, 3, 4, 5];
let mixed = ["hello", 42, true, null];

// Accessing elements (index starts at 0)
console.log(fruits[0]);   // "apple"
console.log(fruits[1]);   // "banana"
console.log(fruits.length); // 3

// Modifying elements
fruits[0] = "grape";
console.log(fruits);  // ["grape", "banana", "orange"]
📄 Array Methods
let fruits = ["apple", "banana", "orange"];

// Add elements
fruits.push("grape");        // Add to end
fruits.unshift("mango");     // Add to start

// Remove elements
fruits.pop();                // Remove from end
fruits.shift();              // Remove from start

// Find elements
let index = fruits.indexOf("banana");
let found = fruits.find(f => f.length > 5);
let exists = fruits.includes("orange");

// Transform arrays
let upper = fruits.map(f => f.toUpperCase());
let long = fruits.filter(f => f.length > 5);
let total = [1, 2, 3].reduce((sum, n) => sum + n, 0);

// Sort
let nums = [3, 1, 4, 1, 5, 9];
nums.sort((a, b) => a - b);  // [1, 1, 3, 4, 5, 9]

// Other useful methods
fruits.join(", ");           // "apple, banana, orange"
fruits.slice(1, 2);         // ["banana"]
fruits.splice(1, 1);        // Removes "banana"

Objects

Objects store data as key-value pairs. They're like dictionaries or maps.

📄 Object Basics
// Creating objects
let person = {
    name: "John",
    age: 25,
    isStudent: true,
    hobbies: ["reading", "gaming"]
};

// Accessing values
console.log(person.name);        // "John"
console.log(person["age"]);      // 25
console.log(person.hobbies[0]);  // "reading"

// Modifying values
person.age = 26;
person.email = "john@email.com";

// Deleting values
delete person.isStudent;

// Object methods
let calculator = {
    add(a, b) { return a + b; },
    subtract(a, b) { return a - b; }
};
console.log(calculator.add(5, 3));  // 8
