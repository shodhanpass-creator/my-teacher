DOM Manipulation

📖 Reading time: 25 minutes 🎯 Difficulty: Intermediate

What is the DOM?

The DOM (Document Object Model) is a tree-like representation of your HTML that JavaScript can read and modify.

💡 Think of it this way:

When the browser reads your HTML, it creates a family tree of all elements. JavaScript can climb this tree to find any element and change it - its content, style, or even add/remove elements!

HTML Code: DOM Tree: <html> html ├── <head> / \ │ └── <title> head body │ └── "My Page" | / \ └── <body> title h1 p ├── <h1> | | | │ └── "Hello" "My Page" "Hello" "World" └── <p> └── "World"

Selecting Elements

To manipulate elements, you first need to find them in the DOM.

📄 Selecting Elements
// By ID (returns single element)
let header = document.getElementById("header");

// By class (returns collection)
let items = document.getElementsByClassName("item");

// By tag name (returns collection)
let paragraphs = document.getElementsByTagName("p");

// CSS Selector (returns first match)
let first = document.querySelector(".card");
let btn = document.querySelector("#submit-btn");

// CSS Selector (returns ALL matches)
let allCards = document.querySelectorAll(".card");
let allLinks = document.querySelectorAll("a");
SELECTOR METHODS: getElementById("id") → One element getElementsByClassName() → Collection (live) getElementsByTagName() → Collection (live) querySelector() → First match querySelectorAll() → All matches (NodeList)

Changing Content

📄 Modifying Content
let element = document.getElementById("demo");

// innerHTML - gets/sets HTML content
element.innerHTML = "<strong>Hello!</strong>";

// textContent - gets/sets text only
element.textContent = "Hello!";

// innerText - gets/sets visible text
element.innerText = "Hello!";

// Create new HTML content
element.innerHTML = `
    <h2>New Heading</h2>
    <p>New paragraph</p>
`;
⚠️ Security Warning:

Never use innerHTML with user input! It can cause XSS attacks. Use textContent for user-provided content.

Changing Styles

📄 Modifying Styles
let box = document.getElementById("box");

// style property (inline styles)
box.style.backgroundColor = "blue";
box.style.color = "white";
box.style.padding = "20px";
box.style.borderRadius = "8px";
box.style.display = "none";

// Using classList (BETTER!)
box.classList.add("active");        // Add class
box.classList.remove("active");     // Remove class
box.classList.toggle("active");     // Toggle class
box.classList.contains("active");   // Check if class exists

// Replace all classes
box.className = "new-class";
✅ Best Practice:

Use classList instead of style property. It's cleaner and keeps your styles in CSS where they belong.

Changing Attributes

📄 Modifying Attributes
let link = document.querySelector("a");

// Get attribute
let href = link.getAttribute("href");

// Set attribute
link.setAttribute("href", "https://google.com");
link.setAttribute("target", "_blank");

// Remove attribute
link.removeAttribute("target");

// Check if attribute exists
let hasTarget = link.hasAttribute("target");

// Using properties directly
link.href = "https://google.com";
link.id = "main-link";

Creating Elements

📄 Creating & Adding Elements
// Create a new element
let newDiv = document.createElement("div");
newDiv.textContent = "I'm new here!";
newDiv.classList.add("card");

// Add to the page
document.body.appendChild(newDiv);  // Add to end of body

// Add to specific parent
let container = document.getElementById("container");
container.appendChild(newDiv);

// Insert before another element
let ref = document.getElementById("reference");
container.insertBefore(newDiv, ref);

// Remove element
container.removeChild(newDiv);

// Clone element
let clone = newDiv.cloneNode(true);  // true = deep clone
container.appendChild(clone);

// Replace element
let old = document.getElementById("old");
container.replaceChild(newDiv, old);
📄 Build a Complete Card
// Create a complete card element
function createCard(title, description) {
    let card = document.createElement("div");
    card.classList.add("card");
    
    card.innerHTML = `
        <h3>${title}</h3>
        <p>${description}</p>
        <button onclick="this.parentElement.remove()">
            Delete
        </button>
    `;
    
    return card;
}

// Add card to page
let card = createCard("My Title", "My Description");
document.getElementById("container").appendChild(card);

Traversing the DOM

You can navigate through the DOM tree to find related elements.

📄 DOM Traversal
let element = document.getElementById("current");

// Parent elements
let parent = element.parentElement;
let grandparent = element.closest(".section");

// Child elements
let firstChild = element.firstElementChild;
let lastChild = element.lastElementChild;
let children = element.children;  // HTMLCollection

// Sibling elements
let next = element.nextElementSibling;
let prev = element.previousElementSibling;

// All children (including text nodes)
let allNodes = element.childNodes;

Event Handling

📄 Adding Event Listeners
let button = document.getElementById("myButton");

// Method 1: addEventListener (BEST)
button.addEventListener("click", function() {
    alert("Button clicked!");
});

// Method 2: Using named function
function handleClick() {
    console.log("Clicked!");
}
button.addEventListener("click", handleClick);

// Remove event listener
button.removeEventListener("click", handleClick);

// Event object
button.addEventListener("click", function(event) {
    console.log("Clicked at:", event.clientX, event.clientY);
    console.log("Target:", event.target);
});
📄 Common Events
// Mouse events
element.addEventListener("click", handler);
element.addEventListener("dblclick", handler);
element.addEventListener("mouseenter", handler);
element.addEventListener("mouseleave", handler);

// Keyboard events
document.addEventListener("keydown", handler);
document.addEventListener("keyup", handler);

// Form events
input.addEventListener("input", handler);
input.addEventListener("change", handler);
form.addEventListener("submit", handler);

// Window events
window.addEventListener("resize", handler);
window.addEventListener("scroll", handler);
window.addEventListener("load", handler);
