Lesson 2: How Browsers Work

📖 Reading time: 12 minutes 🎯 Difficulty: Beginner 📝 Lesson 2 of 6

What is a Browser?

A web browser is a program that reads HTML files and shows you the webpage. You're using one right now! Common browsers include:

  • Google Chrome - Made by Google
  • Mozilla Firefox - Made by Mozilla
  • Safari - Made by Apple
  • Microsoft Edge - Made by Microsoft
💡 Think of it this way:

A browser is like a TV screen. Your HTML file is like a TV show. The browser reads the show (HTML) and displays it on the screen (your monitor).

The DOM Tree

When the browser reads HTML, it creates something called the DOM (Document Object Model). Think of it as a family tree of your HTML elements.

📄 HTML Code
<html>
    <head>
        <title>My Page</title>
    </head>
    <body>
        <h1>Welcome</h1>
        <p>Hello!</p>
    </body>
</html>
THE DOM TREE (Family Tree): html ← Great-grandparent / \ head body ← Grandparents / / \ title h1 p ← Children | | | "My Page" "Welcome" "Hello!" ← Text (leaves)
✅ Why Does This Matter?

JavaScript uses this tree to find and change elements. When you click a button and something changes on the page, JavaScript is climbing this tree to find the right element and update it!

How HTML Becomes a Webpage

The browser processes your HTML in a specific order:

  1. Parse HTML - The browser reads your HTML code line by line, from top to bottom
  2. Build DOM - It creates a tree structure of all elements
  3. Load CSS - It reads your CSS files and applies styles
  4. Build CSSOM - It creates a tree of all styles (CSS Object Model)
  5. Render Tree - It combines DOM and CSSOM
  6. Layout - It calculates where everything goes on screen
  7. Paint - It draws everything you see
THE RENDERING PIPELINE: HTML File │ ▼ ┌─────────┐ │ PARSE │ ← Read HTML code └────┬────┘ │ ▼ ┌─────────┐ │ DOM │ ← Build element tree └────┬────┘ │ ▼ ┌─────────┐ │ CSSOM │ ← Build style tree (from CSS) └────┬────┘ │ ▼ ┌──────────┐ │RENDER │ ← Combine DOM + CSSOM │TREE │ └────┬─────┘ │ ▼ ┌─────────┐ │ LAYOUT │ ← Calculate positions & sizes └────┬────┘ │ ▼ ┌─────────┐ │ PAINT │ ← Draw pixels on screen └────┬────┘ │ ▼ 👁️ YOU SEE THE WEBPAGE!

What is CSS?

CSS stands for Cascading Style Sheets. If HTML is the skeleton of a webpage, CSS is the clothing and makeup.

💡 Think of it this way:

HTML is like a naked mannequin in a store. CSS is the clothes, makeup, and accessories that make it look beautiful!

📄 Example: HTML Without CSS
<h1>This is a heading</h1>
<p>This is a paragraph</p>

Result: Plain black text on white background. Boring!

📄 Example: HTML With CSS
<style>
    h1 { color: blue; font-size: 36px; }
    p { color: gray; font-size: 18px; }
</style>
<h1>This is a heading</h1>
<p>This is a paragraph</p>

Result: Beautiful blue heading and gray paragraph!

What is JavaScript?

JavaScript makes your webpage interactive. Without JavaScript, a webpage is just a static document. With JavaScript, users can click buttons, fill forms, play games, and more.

💡 Think of it this way:

If HTML is the skeleton and CSS is the clothing, then JavaScript is the brain and muscles. It makes the page think and move!

📄 Example: JavaScript in Action
<button onclick="sayHello()">Click Me!</button>

<script>
    function sayHello() {
        alert('Hello! You clicked the button!');
    }
</script>

When you click the button, a popup appears!
