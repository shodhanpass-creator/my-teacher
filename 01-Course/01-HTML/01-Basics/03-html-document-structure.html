Lesson 3: HTML Document Structure

📖 Reading time: 15 minutes 🎯 Difficulty: Beginner 📝 Lesson 3 of 6

The HTML Boilerplate

Every HTML document follows the same basic structure. This is called the boilerplate. Think of it like a recipe - you always need the same ingredients, but you can change the flavors.

📄 The Complete HTML5 Boilerplate
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="My website description">
    <meta name="keywords" content="html, css, javascript">
    <meta name="author" content="Your Name">
    <title>My Website</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <!-- Your content goes here -->
</body>
</html>

Let me explain every single line in detail:

Line-by-Line Explanation

Line 1: <!DOCTYPE html>

📖 What is DOCTYPE?

The DOCTYPE declaration tells the browser which version of HTML to use. HTML5 uses <!DOCTYPE html>. Older versions had longer declarations.

Why it matters: Without it, the browser might use "quirks mode" which causes inconsistent rendering.

Line 2: <html lang="en">

📖 The Root Element

The <html> tag is the root element - everything else goes inside it. The lang="en" attribute tells the browser the page is in English.

Why lang matters: It helps screen readers (for blind users) pronounce words correctly, and helps search engines understand the language.

Line 3: <meta charset="UTF-8">

📖 Character Encoding

UTF-8 supports every character from every language - English, Chinese, Arabic, emojis, and more. Without this, special characters would show as garbled text.

Line 4: <meta name="viewport"...>

📖 Mobile Responsiveness

This meta tag is essential for mobile devices. It tells the browser to set the width to the device's width and start at 100% zoom. Without it, your site would look tiny on phones.

Line 5-7: Meta Tags for SEO

📖 Search Engine Optimization

description - Shows in Google search results under your link
keywords - Helps search engines understand your page
author - Credits the creator of the page

Line 8: <title>

📖 Browser Tab Title

This is the text that appears in the browser tab and bookmark. It's also what shows in search results as the clickable link.

Line 9: <link rel="stylesheet" href="styles.css">

📖 Connecting CSS

This links an external CSS file to style your HTML. The rel="stylesheet" tells the browser "this is a stylesheet" and href points to the CSS file location.

The <head> vs <body> Difference

╔══════════════════════════════════════════════════════════════╗ ║ <head> vs <body> ║ ╚══════════════════════════════════════════════════════════════╝ <head> SECTION (What the browser needs to KNOW) ┌─────────────────────────────────────────────────────┐ │ • Page title (shows in browser tab) │ │ • Meta information (description, keywords) │ │ • Links to CSS files (styles) │ │ • Links to JavaScript files (behavior) │ │ • Favicon (little icon in browser tab) │ │ │ │ Think: The LABEL on a jar of jam │ │ (Describes what's inside, but you don't eat it) │ └─────────────────────────────────────────────────────┘ <body> SECTION (What the user SEES) ┌─────────────────────────────────────────────────────┐ │ • Headings (h1, h2, h3...) │ │ • Paragraphs (p) │ │ • Images (img) │ │ • Links (a) │ │ • Buttons │ │ • Forms │ │ • Everything visible on the page │ │ │ │ Think: The JAM INSIDE the jar │ │ (What you actually see and enjoy) │ └─────────────────────────────────────────────────────┘

Common Meta Tags

Meta tags provide information about your webpage to browsers and search engines.

📄 Common Meta Tags
<!-- Character encoding -->
<meta charset="UTF-8">

<!-- Mobile viewport -->
<meta name="viewport" content="width=device-width, initial-scale=1.0">

<!-- SEO Description (shows in Google results) -->
<meta name="description" content="Learn web development from scratch">

<!-- SEO Keywords -->
<meta name="keywords" content="html, css, javascript, web development">

<!-- Author -->
<meta name="author" content="John Doe">

<!-- Prevent search engines from indexing -->
<meta name="robots" content="noindex">

<!-- Refresh page every 30 seconds -->
<meta http-equiv="refresh" content="30">

<!-- Redirect to another page after 5 seconds -->
<meta http-equiv="refresh" content="5; url=https://google.com">

<!-- Favicon (icon in browser tab) -->
<link rel="icon" type="image/x-icon" href="favicon.ico">

Linking CSS and JavaScript

📄 External CSS (in <head>)
<head>
    <!-- Method 1: External CSS file (BEST for large projects) -->
    <link rel="stylesheet" href="styles.css">

    <!-- Method 2: Internal CSS (in <head>) -->
    <style>
        body { background-color: #f0f0f0; }
        h1 { color: blue; }
    </style>
</head>
📄 External JavaScript (before </body>)
<body>
    <!-- Your HTML content -->

    <!-- Method 1: External JS file (BEST) -->
    <script src="script.js"></script>

    <!-- Method 2: Internal JS (in <script> tag) -->
    <script>
        console.log('Hello from JavaScript!');
    </script>
</body>
⚠️ Where to Place Script Tags?

CSS goes in <head> so styles load before content (prevents flash of unstyled content).

JavaScript goes before </body> so HTML loads first, then scripts run (faster page load).

What is a Favicon?

A favicon is the tiny icon that appears in the browser tab. It helps users identify your website.

Browser Tab: ┌────────────────────────────────────┐ │ 📁 My Website - Google Chrome │ │ │ │ ^^^^ │ │ This is the favicon! │ │ │ └────────────────────────────────────┘
📄 Adding a Favicon
<head>
    <link rel="icon" type="image/x-icon" href="favicon.ico">
    <!-- Or for PNG images: -->
    <link rel="icon" type="image/png" href="favicon.png">
    <!-- Or for SVG images: -->
    <link rel="icon" type="image/svg+xml" href="favicon.svg">
</head>

Complete Example

📄 Complete HTML5 Document
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Welcome to my awesome website!">
    <title>My Awesome Website</title>
    <link rel="icon" href="favicon.ico">
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <header>
        <h1>Welcome to My Website</h1>
        <nav>
            <a href="index.html">Home</a>
            <a href="about.html">About</a>
            <a href="contact.html">Contact</a>
        </nav>
    </header>

    <main>
        <h2>About Me</h2>
        <p>I am learning web development!</p>
    </main>

    <footer>
        <p>&copy; 2026 My Website</p>
    </footer>

    <script src="script.js"></script>
</body>
</html>
