Lesson 1: What is HTML?

📖 Reading time: 15 minutes 🎯 Difficulty: Beginner 📝 Lesson 1 of 6

What is HTML?

HTML stands for HyperText Markup Language. Let's break down every word:

  • HyperText = Text that can link to other text (like clicking a link on a website)
  • Markup = Tags that describe the structure of content
  • Language = A system of rules that computers understand
💡 Think of it this way:

HTML is like the skeleton of a house. It defines where the walls, doors, and windows go. Without HTML, a website has no structure - just like a house without a frame would collapse.

Why Does HTML Exist?

The internet was created so computers could share information. But computers need a special language to understand how to display that information. HTML is that language. It tells the browser: "This is a heading," "This is a paragraph," "This is a link."

How Does the Browser Read HTML?

When you type a web address and press Enter, here's what happens:

Step 1: You type "google.com" and press Enter | Step 2: Your browser sends a request to Google's server | Step 3: Google's server sends back an HTML file | Step 4: Your browser reads the HTML file line by line | Step 5: The browser builds a tree structure (called DOM) | Step 6: The browser draws everything on your screen | Result: You see a beautiful webpage!
✅ Simple Explanation:

The browser is like a translator. It reads HTML code and translates it into something you can see - buttons, images, text, and more!

Your First HTML File

Let's create your very first HTML file. Every HTML file follows this basic structure:

📄 Example: Basic HTML Structure
<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My First Webpage</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>This is my first webpage.</p>
</body>
</html>

Let's explain every single line:

Line 1: <!DOCTYPE html>

This tells the browser: "Hey browser, this is an HTML5 document." It's like showing your ID at the door. Without it, the browser might get confused about what version of HTML you're using.

Line 2: <html lang="en">

This is the root element. Everything in your HTML file goes inside this tag. The lang="en" part tells the browser the page is in English.

Line 3: <head>

The <head> section contains information about the page that users don't see directly. It's like the label on a jar - it describes what's inside.

Line 4: <meta charset="UTF-8">

This tells the browser to use UTF-8 character encoding. Without this, special characters like é, ñ, or ü might show up as weird symbols.

Line 5: <meta name="viewport"...>

This makes your website look good on phones and tablets. Without it, your site would look tiny on mobile devices.

Line 6: <title>My First Webpage</title>

This is the text that appears in the browser tab. Try opening the file and look at the tab!

Line 8-12: <body>...</body>

The <body> contains everything that users can see - headings, paragraphs, images, buttons, etc.

Line 9: <h1>Hello, World!</h1>

This creates a big heading. Think of it like the title of a book chapter.

Line 10: <p>This is my first webpage.</p>

This creates a paragraph of text.

Expected Output in Browser:

Hello, World!

This is my first webpage.

Understanding HTML Tags

HTML uses tags to mark up content. A tag is a special word enclosed in angle brackets < >.

Most HTML tags come in PAIRS: <tagname> ← Opening tag (starts here) Content goes here </tagname> ← Closing tag (ends here) ← has a slash / Example: <p>Hello</p> ^^^^ ^^^ Opening tag Closing tag Some tags are SELF-CLOSING (no content inside): <br> ← Line break <hr> ← Horizontal line <img> ← Image
⚠️ Common Beginner Mistake:

Forgetting to close tags! Always make sure every opening tag has a closing tag (except self-closing tags). The browser might still display your content, but it can cause layout problems.

Nesting Elements

You can put elements inside other elements. This is called nesting. Think of it like Russian dolls - smaller dolls go inside bigger dolls.

📄 Example: Nesting Elements
<body>
    <h1>My Website</h1>
    <p>Welcome to <strong>my</strong> website!</p>
</body>
NESTING RULES: <body> ← Parent (contains others) <h1>My Website</h1> ← Child of body <p>Welcome to ← Child of body <strong>my</strong> ← Child of p (grandchild of body) </p> </body> Think of it like a FAMILY TREE: - Body is the parent - h1 and p are children - strong is a grandchild

HTML Elements Overview

HTML has many elements. Here's a quick overview of the main categories:

Category Elements Purpose
Text p, h1-h6, span, strong, em Display text content
Links a, link Connect to other pages
Lists ul, ol, li, dl Organize items
Media img, video, audio Show images and play media
Forms form, input, button Collect user information
Structure div, header, footer, nav Organize page layout
Table table, tr, td, th Display data in rows/columns

How to Create an HTML File

Follow these steps to create your first HTML file:

  1. Open a text editor (like Notepad, VS Code, or Sublime Text)
  2. Type the HTML code
  3. Save the file with a .html extension (like index.html)
  4. Open the file in your web browser (double-click the file)
  5. See your webpage!
💡 Pro Tip:

Always save HTML files with .html extension. If you save as .txt, the browser won't know it's a webpage!

HTML Comments

Comments are notes you leave in your code for yourself or other developers. They are not shown on the webpage.

📄 Example: HTML Comments
<!-- This is a comment -->

<!--
    This is a multi-line comment.
    You can write as many lines as you want.
    The browser ignores everything here.
-->

<h1>This heading is visible</h1>

<!-- This paragraph is hidden from users -->
<p>This paragraph is visible.</p>
✅ Why Use Comments?
  • Explain complex code to yourself
  • Leave notes for other developers
  • Temporarily hide code without deleting it
  • Organize your code into sections
