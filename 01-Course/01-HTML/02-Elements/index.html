HTML Elements Reference

Complete guide to every HTML element with examples and explanations.

📝 Text Elements

<h1> to <h6>
Heading Elements

Headings define the title or subtitle of a page. <h1> is the largest and most important, <h6> is the smallest.

When to use: Use <h1> for the main page title (only ONE per page). Use <h2> for section titles, <h3> for subsections, etc.

When NOT to use: Don't use headings just to make text big. Use CSS for styling.

Example
<h1>Main Title (biggest)</h1>
<h2>Section Title</h2>
<h3>Subsection Title</h3>
<h4>Smaller Subsection</h4>
<h5>Even Smaller</h5>
<h6>Smallest Heading</h6>

Main Title (biggest)

Section Title

Subsection Title

Smaller Subsection

Even Smaller
Smallest Heading
<p>
Paragraph Element

The paragraph element defines a block of text. Browsers add space before and after paragraphs automatically.

Example
<p>This is my first paragraph.</p>
<p>This is my second paragraph. Browsers add spacing between paragraphs automatically.</p>
<br>
Line Break (Self-closing)

Inserts a single line break. Use sparingly - use CSS margin/padding instead for spacing.

Example
<p>First line<br>Second line</p>
<hr>
Horizontal Rule (Self-closing)

Creates a horizontal line to separate content sections.

Example
<p>Content above</p>
<hr>
<p>Content below</p>
<strong>
Strong Importance

Makes text bold and important. Screen readers emphasize this text. Use for important content.

Example
<p>This is <strong>very important</strong> text.</p>

This is very important text.

<em>
Emphasis

Makes text italic and emphasized. Screen readers change tone when reading this.

Example
<p>This is <em>emphasized</em> text.</p>

This is emphasized text.

<b> and <i>
Bold and Italic (No Emphasis)

<b> makes text bold without importance. <i> makes text italic without emphasis. Use <strong> and <em> instead when possible.

Example
<p>This is <b>bold</b> text.</p>
<p>This is <i>italic</i> text.</p>
<mark>
Highlighted Text

Marks text with a yellow background, like using a highlighter pen.

Example
<p>This is <mark>highlighted</mark> text.</p>

This is highlighted text.

<small>
Small Text

Makes text smaller. Use for copyright, legal text, or side comments.

Example
<p>Normal text</p>
<p><small>This is smaller text</small></p>
<sub> and <sup>
Subscript and Superscript

<sub> makes text smaller and lower (like H₂O). <sup> makes text smaller and higher (like x²).

Example
<p>H<sub>2</sub>O (water)</p>
<p>x<sup>2</sup> (x squared)</p>

H2O (water)     x2 (x squared)

<del> and <ins>
Deleted and Inserted Text

<del> shows text that was removed (with a line through it). <ins> shows text that was added (underlined).

Example
<p>Price: <del>$50</del> <ins>$30</ins></p>

Price: $50 $30

<blockquote>
Block Quotation

Used for long quotations from another source. Browsers usually indent this content.

Example
<blockquote cite="https://example.com">
    <p>This is a long quote from another source.</p>
</blockquote>
<q>
Inline Quotation

For short inline quotations. Browsers automatically add quotation marks.

Example
<p>She said <q>hello</q> to me.</p>

She said hello to me.

<abbr>
Abbreviation

Defines an abbreviation or acronym. Shows full text on hover.

Example
<p>I study at <abbr title="Massachusetts Institute of Technology">MIT</abbr>.</p>

I study at MIT.

🔗 Link Elements

<a>
Anchor (Link) Element

Creates hyperlinks to other pages, files, or locations. The most important element on the web!

Attributes:

  • href - URL to link to (required)
  • target="_blank" - Opens in new tab
  • rel="noopener" - Security for external links
  • download - Downloads the linked file
Example
<a href="https://google.com">Visit Google</a>

<a href="https://google.com" target="_blank" rel="noopener">
    Open Google in new tab
</a>

<a href="file.pdf" download>Download PDF</a>

<a href="mailto:email@example.com">Send Email</a>

📋 List Elements

<ul>, <ol>, <li>
Unordered and Ordered Lists

<ul> = Bulleted list (unordered). <ol> = Numbered list (ordered). <li> = List item (goes inside ul or ol).

Example
<!-- Unordered (bullet) list -->
<ul>
    <li>Apples</li>
    <li>Bananas</li>
    <li>Oranges</li>
</ul>

<!-- Ordered (numbered) list -->
<ol>
    <li>First step</li>
    <li>Second step</li>
    <li>Third step</li>
</ol>
  • Apples
  • Bananas
  • Oranges
  1. First step
  2. Second step
  3. Third step
<dl>, <dt>, <dd>
Description List

Used for key-value pairs like definitions, glossaries, or FAQ items.

Example
<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language - the structure of web pages</dd>

    <dt>CSS</dt>
    <dd>Cascading Style Sheets - the appearance of web pages</dd>
</dl>

🖼️ Media Elements

<img>
Image (Self-closing)

Embeds an image. Always include alt attribute for accessibility.

Attributes:

  • src - Image path (required)
  • alt - Alternative text (required for accessibility)
  • width and height - Dimensions
  • loading="lazy" - Lazy loading for performance
Example
<img src="photo.jpg" alt="A beautiful sunset" width="400" height="300">

<!-- Lazy loaded image -->
<img src="photo.jpg" alt="A beach" loading="lazy">
<video>
Video Player

Embeds a video player with controls.

Example
<video controls width="640" height="360">
    <source src="video.mp4" type="video/mp4">
    <source src="video.webm" type="video/webm">
    Your browser does not support video.
</video>
<audio>
Audio Player

Embeds an audio player.

Example
<audio controls>
    <source src="song.mp3" type="audio/mpeg">
    Your browser does not support audio.
</audio>
<iframe>
Inline Frame

Embeds another webpage inside your page. Common for YouTube videos or maps.

Example
<iframe src="https://www.youtube.com/embed/VIDEO_ID" 
        width="560" height="315" 
        frameborder="0" 
        allowfullscreen>
</iframe>

🏗️ Semantic Structure Elements

<header>
Page Header

Defines the header section of a page or section. Usually contains logo, navigation, and title.

Example
<header>
    <h1>My Website</h1>
    <nav>
        <a href="home.html">Home</a>
        <a href="about.html">About</a>
    </nav>
</header>
<nav>
Navigation

Contains navigation links. Helps search engines understand your site structure.

Example
<nav>
    <ul>
        <li><a href="home.html">Home</a></li>
        <li><a href="about.html">About</a></li>
        <li><a href="contact.html">Contact</a></li>
    </ul>
</nav>
<main>
Main Content

The main content of the page. Only ONE <main> per page. Helps screen readers skip to content.

Example
<main>
    <article>
        <h2>Blog Post Title</h2>
        <p>Post content here...</p>
    </article>
</main>
<footer>
Page Footer

Contains footer information like copyright, contact, and social links.

Example
<footer>
    <p>&copy; 2026 My Website</p>
    <a href="privacy.html">Privacy Policy</a>
</footer>
<section>
Section

Groups related content together. Like chapters in a book.

Example
<section>
    <h2>About Us</h2>
    <p>We are a company that...</p>
</section>

<section>
    <h2>Our Services</h2>
    <p>We offer...</p>
</section>
<article>
Article

Self-contained content that could be distributed independently (blog post, news story, forum post).

Example
<article>
    <h2>My Blog Post</h2>
    <p>Published on Jan 1, 2026</p>
    <p>Content of the blog post...</p>
</article>
<aside>
Sidebar Content

Content related to the main content but can stand alone (sidebars, ads, related links).

Example
<aside>
    <h3>Related Articles</h3>
    <ul>
        <li><a href="post1.html">Post 1</a></li>
        <li><a href="post2.html">Post 2</a></li>
    </ul>
</aside>
<div> and <span>
Generic Containers

<div> = Block container (takes full width). <span> = Inline container (only takes needed width). Use when no semantic element fits.

Example
<div style="background: yellow; padding: 20px;">
    <p>This is a div (block element)</p>
    <p>It takes full width</p>
</div>

<p>This is <span style="color: red;">red text</span> in a paragraph.</p>

📊 Table Elements

<table>, <tr>, <td>, <th>
Tables

Tables display data in rows and columns.

  • <table> - The table container
  • <tr> - Table row
  • <th> - Table header (bold and centered)
  • <td> - Table data cell
Example
<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
    <tr>
        <td>John</td>
        <td>25</td>
    </tr>
    <tr>
        <td>Jane</td>
        <td>30</td>
    </tr>
</table>

📝 Form Elements

<form>
Form Container

Contains form elements for collecting user input.

Attributes:

  • action - Where to send form data
  • method - HTTP method (GET or POST)
Example
<form action="/submit" method="POST">
    <label for="name">Name:</label>
    <input type="text" id="name" name="name" required>

    <label for="email">Email:</label>
    <input type="email" id="email" name="email" required>

    <button type="submit">Submit</button>
</form>
<input>
Input Field (Self-closing)

The most versatile form element. Different types for different data.

Common Types:

  • type="text" - Single line text
  • type="password" - Hidden text (dots)
  • type="email" - Email validation
  • type="number" - Numbers only
  • type="date" - Date picker
  • type="checkbox" - Check box
  • type="radio" - Radio button
  • type="file" - File upload
Example
<input type="text" placeholder="Enter name">
<input type="email" placeholder="Enter email">
<input type="number" min="0" max="100">
<input type="date">
<input type="checkbox" id="agree">
<label for="agree">I agree</label>
<input type="radio" name="gender" id="male">
<label for="male">Male</label>
<textarea>
Multi-line Text Input

For longer text input like comments or messages.

Example
<textarea name="message" rows="5" cols="40" placeholder="Type your message..."></textarea>
<select> and <option>
Dropdown List

Creates a dropdown menu.

Example
<select name="color">
    <option value="">Select a color</option>
    <option value="red">Red</option>
    <option value="blue">Blue</option>
    <option value="green">Green</option>
</select>
<button>
Button

Clickable button. Use type="submit" for form submission, type="button" for JavaScript actions.

Example
<button type="submit">Submit Form</button>
<button type="button" onclick="alert('Clicked!')">Click Me</button>

✨ Special Elements

<details> and <summary>
Disclosure Widget (Accordion)

Creates a collapsible section. Click the summary to show/hide content.

Example
<details>
    <summary>Click to learn more</summary>
    <p>This content is hidden by default.</p>
    <p>Click the summary to toggle visibility.</p>
</details>
<dialog>
Dialog Box

Creates a modal dialog box.

Example
<dialog id="myDialog">
    <p>This is a dialog box!</p>
    <button onclick="myDialog.close()">Close</button>
</dialog>

<button onclick="myDialog.showModal()">Open Dialog</button>
<template>
Template Content

Contains content that is not rendered immediately but can be activated by JavaScript.

Example
<template id="myTemplate">
    <div class="card">
        <h2>Card Title</h2>
        <p>Card content</p>
    </div>
</template>

<script>
    const template = document.getElementById('myTemplate');
    const clone = template.content.cloneNode(true);
    document.body.appendChild(clone);
</script>
<canvas>
Drawing Canvas

Used for drawing graphics with JavaScript (charts, games, animations).

Example
<canvas id="myCanvas" width="400" height="200"></canvas>

<script>
    const canvas = document.getElementById('myCanvas');
    const ctx = canvas.getContext('2d');
    ctx.fillStyle = 'blue';
    ctx.fillRect(10, 10, 100, 50);
</script>
<svg>
Scalable Vector Graphics

Used for scalable vector graphics (icons, logos, charts).

Example
<svg width="100" height="100">
    <circle cx="50" cy="50" r="40" fill="blue" />
</svg>
