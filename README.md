## 🎯 The 6-Phase Curriculum

| Phase | Focus | Exit Condition |
|---|---|---|
| **0** | Foundation Repair (Git, CSS theory, security, forms, responsive) | All beginner projects hardened |
| **1** | Web Intermediate (Grid, animations, TypeScript, tooling) | 3 projects deployed publicly |
| **2** | Front-End Advanced (React, routing, testing) | React SPA + API, deployed |
| **3** | Python Path (basics → automation → web) | Scripts solving real problems |
| **4** | Backend / Full-Stack (Express, SQL, auth, deploy) | Full-stack app with users |
| **5** | Professional Engineering & Career (code review, interviews, portfolio) | Portfolio live, interviewing |

## 📖 How to Use

1. Open `index.html` in your browser
2. Check `ROADMAP.md` to see your current phase and mission
3. Complete lessons **in mission order** (not folder order)
4. Build each project's brief before moving on — **projects are the curriculum**
5. Homework is mandatory: reading without doing = no progress
